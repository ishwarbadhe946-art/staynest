# StayNest - Node.js Basic Applications

## Practical No. 7

Develop Basic Node.js Applications Demonstrating REPL, HTTP Server, File System, Buffers, Streams, and Event Loop.

## Applications Included

### 1. REPL
Demonstrates the Node.js Read-Eval-Print-Loop environment.

### 2. HTTP Server
Creates a basic HTTP server using Node.js built-in HTTP module.

### 3. File System
Demonstrates creating, reading and modifying files using the fs module.

### 4. Buffers
Demonstrates creating, writing, reading and converting Node.js Buffers.

### 5. Streams
Demonstrates reading and writing data using Node.js streams.

### 6. Event Loop
Demonstrates synchronous execution, Promise callbacks and setTimeout callbacks.

## Run Commands

REPL:

node

HTTP Server:

node 02-http-server/server.js

File System:

node 03-file-system/file-system.js

Buffers:

node 04-buffers/buffer-demo.js

Streams:

node 05-streams/stream-demo.js

Event Loop:

node 06-event-loop/event-loop.js
